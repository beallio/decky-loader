# Troubleshooting

Common issues and quick fixes in plain English.

---

## Decky does not appear in Gaming Mode

1. **Restart your Steam Deck** once after installing or switching back from Desktop Mode.
2. If Decky still does not show up, download and run the **newest installer** again ([Installation Guide](./installation.md)), then restart.
   - Installer scripts from before `v3.3.1-rust.1-rc.5` did not enable Steam remote debugging on a Steam Deck that had never previously had Decky installed.

---

## A plugin shows "This plugin needs root"

Root plugins (such as PowerTools) are disabled by default for security. Open `Install-Decky-Rust.desktop` and pick **Enable Root Plugins**, or see the [Root Plugins Guide](./root-plugins.md).

---

## A plugin shows "Decky could not start"

That individual plugin failed to start cleanly, while Decky itself stayed online. Open Decky settings -> **Plugins**, then update or uninstall that plugin.

---

## A plugin shows an error after switching to Steam Beta

Steam Beta builds changed how Gaming Mode is built. Valve's change renamed almost all CSS class names and moved most React components and internal stores. Some plugins expect the old names.

- Decky itself works on Steam Stable and Steam Beta. No extra steps are needed.
- A plugin may need an update from its author for Steam Beta. Open Decky settings -> **Plugins**, then select **Update plugins**.
- If you need that plugin now, switch back to **Steam Stable** in Steam Settings -> **System**.

---

## Self-update fails from an older release

Two older preview ranges cannot self-update inside Gaming Mode because of runtime packaging upgrades:

- **Running `v3.2.10-rust.8-rc.1` through `rc.10`:** Cannot self-update directly to `v3.3.0+`.
- **Error `"bundle requires a frozen CPython 3.11 worker"` (versions up to `v3.3.0-rust.1-rc.12`):** Older CPython 3.11 installers cannot self-update to Python 3.14 builds in Gaming Mode.

**Fix:** Run the graphical installer ([Installation Guide](./installation.md)) or run the terminal installer **once** with `--channel preview`. After that one update, in-app Gaming Mode updates work again.

---

## A plugin stopped working after updating to a Python 3.14 build

This fork runs **Python 3.14.8** (matching Official Decky `v3.3.0+`). A small number of plugins ship precompiled native extensions built only for Python 3.11. Ask the plugin author for a release built for Python 3.14 / Official Decky `v3.3.0+`.

---

## Another program uses port 1337 or 8080

Decky requires **port 1337** (plugin API) and **port 8080** (Steam Chromium debugger).

- **Syncthing** defaults its web interface to `8080`. Change Syncthing's web GUI port to `8384` (or another free port), then restart Decky or reboot.

---

## Installer stops due to low disk space

The installer checks free space before changing anything on disk and aborts safely if space is too low for a backup.

- Free up disk space in `~`, **or** store the backup archive on an SD card or another drive:
  ```sh
  bash install-to-deck.sh --backup-dir /run/media/mmcblk0p1/decky-backups --channel preview
  ```

---

## An install stopped partway through / Reporting a bug

If an installation is interrupted or fails, the installer automatically restores the previous working version and prints the path to its log file.

To get help or file a bug report on **[GitHub Issues](https://github.com/beallio/decky-loader/issues)**:

1. Generate a troubleshooting archive using [collect-debug-info.sh](../../scripts/collect-debug-info.sh):
   ```sh
   bash scripts/collect-debug-info.sh
   ```
2. Attach either the installer log file or the `.zip` archive generated by `collect-debug-info.sh` to your issue report.
